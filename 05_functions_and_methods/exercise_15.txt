EXERCISE 15
Using the code below, classify the identifiers as global, local, or built-in. For our purposes, you may assume this code is the entire program.

Copy Code
def multiply(left, right):
    return left * right

def get_num(prompt):
    return float(input(prompt))

first_number = get_num('Enter the first number: ')
second_number = get_num('Enter the second number: ')
product = multiply(first_number, second_number)
print(f'{first_number} * {second_number} = {product}')


ANSWER (line by line):
multiply: global; left, right: local
left, right: local

get_num: global; prompt: local
float, input: built-in; prompt: local

first_number, get_num: global
second_number, get_num: global
product, multiply, first_number, second_number: global
print: built-in; first_number, second_number, product: global
