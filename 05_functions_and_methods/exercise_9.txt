EXERCISE 9
Without running the following code, what do you think it will do?

Copy Code
def foo(first, second=3, third=2):
    print(first)
    print(second)
    print(third)

foo(42, 3.141592, 2.718)


ANSWER:
The code will print:
42
3.141592
2.718

The supplied arguments override the default values for the parameters and are printed
