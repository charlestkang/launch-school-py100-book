EXERCISE 5
Which of the following values can't be used as a key in a dict object, and why?

Copy Code
'cat'
(3, 1, 4, 1, 5, 9, 2)
['a', 'b']
{'a': 1, 'b': 2}
range(5)
{1, 4, 9, 16, 25}
3
0.0
frozenset({1, 4, 9, 16, 25})


ANSWER
['a', 'b'], 
{'a': 1, 'b': 2}, 
{1, 4, 9, 16, 25}
cannot be used as keys in dict objects because 
they are not hashable.
