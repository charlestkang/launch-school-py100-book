EXERCISE 3
Without running this code, what will it print? Why?

Copy Code
dict1 = {
    "Hitchhiker's Guide to the Galaxy": 42,
    'Monty Python': 'The Life of Brian',
    'Airplane!': "Don't call me Shirley!",
}

dict2 = dict(dict1)
dict2['Monty Python'] = 'Holy Grail'
print(dict1['Monty Python'])

ANSWER
It prints:
"The Life of Brian"

The shallow copy contains no nested mutables, so the key "Monty Python" in dict 2 is reassiged to 
"Holy Grail" but the value assigned to the corresponding key in dict1 remains the same

To be clear, dict2['Monty Python'] is dict1['Monty Python'] at first, though dict2['Monty Python']
is reassigned later in the code.
