EXERCISE 4
Without running this code, what will it print? Why?

Copy Code
dict1 = {
    'a': [1, 2, 3],
    'b': (4, 5, 6),
}

dict2 = dict(dict1)
dict1['a'][1] = 42
print(dict2['a'])
View Our Solution
 
ANSWER:
[1, 42, 3]
The nested list is mutable and the dict2 is a shallow copy so the nested list, being mutable, has
its changes reflected in dict2

BOOK:
Since both dictionaries reference the same nested list, mutating that list through dict1 is 
visible when accessing it through dict2.
